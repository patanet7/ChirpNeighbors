## Scope boundaries

This is code-quality work. The application’s behavior, test assertions, renderer policy, fixture art and provider boundaries remain acceptance constraints. Type annotations and narrow boundary validation must preserve command failure propagation. Additional hardware, toolchain, publication or deployment operations are outside this work.

The starting residual inventory also lists 45 handwritten JS/MJS files without broad static typing and seven nonempty backend tests without strict mypy. Those are separate from the requested declaration, UI Python and simulator work and are not implicitly closed. Generated runtime JavaScript retains its existing generation-drift and runtime checks.
