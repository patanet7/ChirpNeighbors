# Deterministic source inspection

Run with a **new** output directory:

```sh
python validation/sprite-inspection.py --config validation/sprite-inspection-example.json --config-sha256 085b2bb5bc6f0d108431395351f9291daf827419a0f4ca4f5c6a3c1dacb2e056 --out /tmp/my-sprite-inspection
```

Config paths resolve relative to the config file. `sprite-inspection-config.schema.json` documents schema 1; the CLI also validates essential types, bounds and hashes. Every frame, optional mask, action manifest, codec receipt, nominated codec module and supplied evaluation contract is hash-checked before image measurements. The exact config is copied to the output. The optional CLI pin verifies an external config hash; without it the report explicitly records that no external pin was verified. All source/config hashes are checked again after inspection. Existing output directories are refused.

`inspection.json`, numbered candidate/frame JSON files, normal-size light/dark contact sheets and source-pixel overlay PNGs are diagnostics. They are not replacement frames. Fractional CSS canvas dimensions are reported exactly; static PNG contact-sheet dimensions round up to whole display pixels using whole-canvas nearest sampling. Overlays mark the threshold bounding box, pivot and configured contact-probe rectangles. No browser capture, OpenCV, service, image generation, source painting or fitting is used. SciPy labels components when already installed; a four-neighbor fallback needs only Pillow/NumPy.

Each candidate needs `motionIntent.kind`. `motionIntent.registrationExpectedStable` enables the configured stable-region registration check. Optional `stableBodyROI` is `[x,y,width,height]`; optional `stableMaskPNG` is `{file,sha256}` with an explicit L/1 mask matching the source canvas. If both are present their intersection is used. Without either, centroid/bbox changes are report-only and registration is `NOT_EVALUATED`. Head, bill or wing changes outside a supplied stable mask do not contribute to its comparison.

`frames[].expectedPixelTranslation` is an integer source-pixel displacement relative to the first frame's declaration; it defaults to `[0,0]`. The estimator searches within the fixed radius around that declaration and reports observed translation and residual world displacement. An undeclared shifted bitmap can exceed the stable-region offset threshold. Declaring the actual intentional shift makes its residual zero. Ambiguous equal best offsets are reported as warnings. These calculations never transform a candidate. Optional `expectedTrajectory` contains one world-root pair per frame and is reported separately from source drawing coordinates; it does not supply anatomical support.

Optional `contactProbeROIs` contain `{id,rect:[x,y,width,height]}`. Alpha maxima, threshold pixels, lowest rows and pivot-relative baselines are **image proxies**, never accepted toes, pressure or contact. Center suggestions are disabled by default. If enabled, they describe only a hypothetical texture repack: pixels, pivot, contacts and masks must all translate consistently to preserve the rendered world pose. Such a repack does **not** repair visible jitter. Predicted alpha-positive pixel loss is reported; nothing is applied.

Action coverage uses only a hash-bound `actionManifest` with explicit `actionsPointer` pointing to a clip dictionary or a list of IDs/objects with `id`. It compares those keys with `requiredActions`; it does not infer actions from filenames or prove genuine motion. Without a manifest coverage remains `NOT_EVALUATED`.

A codec is **never run** here. `codecReceipt` requires `file`, `sha256`, `frameHashesPointer`, `statusPointer`, and `canonicalSource:{file,sha256,receiptHashPointer}`. The nominated current code file hash must equal the exact receipt value, and its input hash list must equal this candidate's PNG hashes. A single hash string is supported; lists of receipt rows can nominate `frameHashField`. A boolean passed field or explicit PASS/WARN/FAIL/NOT_EVALUATED status can be reused. Optional `rectanglesPointer` reads an actual integer count; no count is estimated. Without these bindings codec status is `NOT_RUN`.

Defaults are predeclared: alpha cutoff 128, maximum stable offset 1 world unit, relative width warning 0.20, search radius 8 source pixels, bright boundary minimum >240 and maximum channel spread 15. White/fringe/component and width warnings are proxies, not subjective art failures. Opaque-only and alpha-cutoff-visible RGB palettes are reported separately. A PASS concerns evaluated raster checks only; unknown coverage/codec/support states stay unknown and no overall art, motion or runtime approval is produced.

The shared evaluation taxonomy is pending. `canonicalDefectId`, severity and confidence remain null, with `canonicalLabelsStatus:PENDING_SHARED_CONTRACT` and `evaluationContractPin:null`. Optional `canonicalEvaluationContract:{file,sha256,labelMapPointer?}` verifies a supplied artifact and, when nominated, its existing unique label IDs. It assigns no labels automatically. Candidate `speciesId`, `context`, `assetId`, `clipId`, `supportRequirement`, `repairDecision` and `reevaluationRefs` are retained verbatim. Repair decisions are caller metadata, not automated art judgments. Optional `reevaluationLinks` may hash-bind an `existingReport` to `existingReportSHA256`; bare reference metadata is not presented as verified evidence.

The one execution smoke uses the parent-nominated existing Crow selected-12 PNG. `sprite-inspection-smoke.json` binds its config/tool/input/output hashes. It is a code-execution check, **not** golden calibration; actual codec remains NOT_RUN. The parent owns the shifted controls, held Bath, masked Sparrow and other golden cases. No threshold was adjusted to test outcomes.
