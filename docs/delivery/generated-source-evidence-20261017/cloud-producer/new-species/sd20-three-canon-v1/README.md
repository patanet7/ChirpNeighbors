# San Diego three-species source starter batch

One real OpenAI native image-generation call produced three new original drawings: adult male Anna's Hummingbird, adult Black Phoebe, and adult California Towhee. `original.png` is the untouched 2060×763 RGBA output; `prompt.txt` retains the exact prompt, and `receipts/generation.json` records the original path, hash and existing finch style reference. There are **zero newly drawn animation clips** in this starter batch.

Each individual has a registered 1024×1024 source, a whole-canvas nearest-neighbor 96×96 RGBA export, a review-only texture manifest, manually identified foot-core contacts, an approximate beak tip, and explicit world-scale metadata. Registration is integer translation; no original pixels were repainted. Three principal alpha≥32 components assign original alpha≥2 pixels to birds; alpha1 residue is excluded from derivatives only. Source margins were verified so no bird pixels are clipped.

The generated sheet did not respect the requested biological size ratios. The intake metadata therefore proposes different presentation densities, giving visible lengths **34, 54 and 78 world pixels** respectively. These are practical bounding-box presentation proxies, not scientifically calibrated anatomical lengths. The original species-length references are 10cm, 16cm and 21–25cm. At a 960px-wide yard rendered 1:1, a world pixel is one CSS pixel. Different viewport scaling changes CSS size; it does not silently change biological metadata.

`review.html` shows these actual normal-size presentations and optional 4× output pixels. `normal-size-preview.png` is a generated art contact sheet with normal world sizes above and 2× output pixels below. It is not an application screenshot. All three are recognizable at the proposed size in this source review. Anna's green upperparts, rose crown/throat and straight bill remain visible; Phoebe's dark peaked silhouette and white belly remain visible; Towhee's bulky brown shape, conical bill and rusty undertail remain visible. Phoebe has a warm cast and stronger pale wing edging than ideal. Towhee feather contrast and all toe detail remain documented for owner review. No continuous motion quality is inferred from stills.

Each `idle` clip is one still held for 90 ticks at 30Hz. This satisfies the existing intake shape for static review. **Movement and interaction are planned, unbound and not visually verified.** Proposed motion: hummingbird hover/dart with a real wing pose or honestly labelled wing rig; phoebe short insect sally/return and optional tail-pump rig; towhee ground hop with an airborne interval. Proposed interactions: flower nectar probe, airborne insect catch and ground peck/scratch respectively.
