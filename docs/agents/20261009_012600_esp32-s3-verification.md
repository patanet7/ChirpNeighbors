## Implemented behavior

- Explicit little-endian 12-byte packet header and fixed 48 kHz PCM16 mono;
  shared C++ serializer, bounded I2S conversion, full-scale negative peak,
  finite settings and sequence/timer wrap checks. Invalid nonempty reads expose
  a sequence discontinuity instead of silently joining audio.
- Independent capture task with fixed buffers and a four-packet static queue.
  Capture never waits for queue space. Reconnect epochs discard old-session
  audio; one masked frame is sent with one `MSG_DONTWAIT` call. A short write
  closes TCP before any WebSocket close frame can follow a partial PCM frame.
  The sender uses the pinned library's protected plain-TCP client; changing the
  library or adding TLS requires revisiting that boundary.
- Runtime settings remain immutable during capture. Validated changes persist
  and restart after a response grace period. Shutdown waits up to 250 ms for
  capture acknowledgement before I2S cleanup. DNS, handshake, SDK operations,
  and total shutdown wall time are not guaranteed nonblocking.
- Receiver entrypoints enforce 48 kHz; queue/assembly/one-consumer PCM windows
  have a 16 MiB storage budget. Uptime remains device metadata and `observed_at`
  remains null. Headless imports, real loopback transport and generated
  identification contract tests remain covered.
- Added pinned development tools, firmware and intake CI gates, an explicit
  synthetic S3 QEMU project, and the [wire protocol](../api/audio-stream-protocol.md).
