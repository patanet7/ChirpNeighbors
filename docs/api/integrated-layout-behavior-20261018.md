# Versioned layout and actor integration

The shared normal-yard runtime combines owner/source-bound placement, seeded actor attention and gait timing, and settled autonomous bathing contacts. Placement remains on the current scene geometry until the separately versioned layered-ground release is admitted. The water ledger remains limited to the active selected basin; cosmetic contacts do not withdraw water.

Five independent contracts are mirrored with the canonical repository: `placement-snapshot-v2`, `placement-command-v2`, `object-inventory-command-v2`, `dev-workbench-command-request-v2` and `behavior-decision-trace-v2`. Every previously published schema and all 323 prior structural baseline entries remain unchanged. The new workbench envelope explicitly requires a nonnegative safe integer revision; a negative probe exposed the portable exporter bound ordering before publication, and the V2 authority now retains the same runtime and structural bound. V1 is untouched.

The integration adds valid null-source and exact-source/ground synthetic seeds plus unknown-field, missing/future-version and invalid-revision negatives. These are technical wire fixtures, never source, rights or physical geometry approval. All new authorities participate in the existing Zod/Ajv/Python corpus, including the copied-workbench V2 envelope.

Validation on Node 24 and Python 3.12: the complete quality gate passes, including 222 suites with 2,982 tests and one existing optional private-source skip; 834 cross-language goldens and 22,583 deterministic mutations pass, retaining 492 explicitly reviewed source-only semantic rejections. Independent authority inventory reports 82 Svelte operations and 136 boundaries, with 55 existing residual gaps. No hosted source execution is claimed where CI did not allocate a runner.

Actual copied normal-yard browser checks cover move, add, remove, undo and reload persistence, shared-clock rain wetting and a completed selected-bird bath. An 18-second actual Chrome capture records generated attention poses. These checks do not certify gait/flight anatomy, relative biological scale, reviewed support contacts, scene-wide snow, multiple advancing basin ledgers or GPU performance. Missing artwork remains a separate acceptance dependency.
