# Canonical generated-art storage — 17 October 2026

This folder contains actual project-generated source sheets, individual sprites, animation previews, exact non-sensitive generation prompts, producer scripts, manifests, hashes/provenance, rejected variants and review records. The owner explicitly authorized adding these project artifacts to this repository, superseding the earlier source-only preservation exclusion for generated images/prompts. Personal photos, recordings, credentials and private standalone research remain outside Git. One personal pet identifier was redacted with both hashes recorded; generated Raven art was retained.

Storage is plain Git in the existing canonical ChirpNeighbors repository. No Git LFS or versioned object store was already configured and no paid service was added. Archives are unpacked and indexed through `packs/` so individual usable files are versioned directly, without a second compressed ZIP copy. `manifest.json` records every original archive SHA-256, byte count, canonical directory and member hash. Original ZIPs remain preserved locally; canonical member files (including reused PR9 producer paths) and `SHA256SUMS.json` provide durable retrieval independent of Library download URLs. Files are below GitHub's100MiB individual-file limit.

`pipeline/candidate-yard/` preserves all currently retained project review packages and catalog snapshots, including prior wrappers; `decoded/` provides usable original/canonical PNGs extracted exactly from those packages. No saved-yard store, resident pin, production configuration or active catalog flag was modified by this storage operation. `pipeline/raven-study-served/atlas.png` preserves the optional-study atlas (same exact bytes as the archived extended sheet).

All244 producer-inventoried files were matched against actual local SHA-256 bytes; see `producer-244-file-reconciliation.json`. Archive-level ZIP CRC/path/symlink/size checks and a source-text secret/ephemeral-URL scan passed before copying. Original source PNGs were not repainted or repaired during intake. Generated HTML/Python are retained source, not executed. Large embedded previews/frame-bank records are producer outputs, not replacement task authority.

**Canonical storage is not art approval, biological calibration, rights clearance, a resident pin or normal-runtime integration.** Existing candidate/rejected statuses and failure reasons remain in each pack. Rejected crow contact cycles, wide steps, palette/anatomy drift and rejected botanical plumes are preserved. Species/scale/contact/occlusion and runtime acceptance remain separate gates. Models/seeds/settings absent from original receipts remain unknown; exact prompt storage does not promise byte-identical regeneration. Native framework remains task authority.
