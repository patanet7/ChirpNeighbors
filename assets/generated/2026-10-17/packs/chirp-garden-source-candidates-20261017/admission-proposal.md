# Bounded admission proposal

This proposes the next art-packing review. It does not implement a second renderer, importer, physics model or runtime schema. Local Chirp owns production code and the authoritative current validator.

1. **Choose one source.** Begin with the standing bird for sprite admission, or the empty bath only after object-media admission exists. Preserve its Library source and SHA-256. Reject the filled bath for physical-water use.
2. **Record the actual contract.** Use the local validator's current file-byte, dimensions, decoded pixel, palette, binary-alpha, frame/rectangle and manifest limits. The transferred bird references described ≤256 edge, ≤64 colors, ≤64 unique frames, ≤65,536 total decoded pixels, ≤4,096 rectangles per frame, ≤16,384 total, and density 1/2/4 for V4. Parent's newer audit adds the 512 KiB file limit. Treat these as evidence to reconcile with the local code, not a newly authored contract. Do not apply bird limits to unimplemented foliage formats or bypass admission through giant inline rectangle data.
3. **Approve a single uniform crop/scale.** The bird proposal is 128 × 96 source pixels at density 2, giving a 64 × 48 world frame. Do not distort the body to fill a rectangle. Annotate source-to-packed transform, baseline, left/right feet and any perch contact using the permitted contact vocabulary. Give all compared variants the same transform and pivot. Existing bath supports stay at ±18, −68; feeder supports at ±18, −24.
4. **Review the alpha/edge choice before conversion.** The source bird contains no 255-alpha pixels, so a rule retaining only fully opaque pixels would erase it. Thresholding at 128 was used only for diagnostics and is not an approved cleanup rule. Image generation is the approved route for visual edge/halo edits. Stop if it cannot create an acceptable source; do not hide halos through arbitrary thresholding or call a successful file check visual approval.
5. **Pack under local ownership after the art decision.** Use a deliberate bounded palette and a documented sampling/alpha policy. Preserve original and packed files separately. Treat every converted frame as a new candidate with its own hash and exact geometry. No conversion output is present in this bundle.
6. **Run the real native validator and inspect the actual target size.** Inspect light, dark and checker backgrounds at 1× world size and integer source magnification. Check beak, eye, toes, tail, silhouette, fringe, detail loss and baseline contact. Save the validator result and screenshot with the exact candidate hash. A pass in one does not imply a pass in the other.
7. **Object/water review is separate.** The empty bath needs an accepted object-media path, exact reviewed water-area and foreground-rim masks, one shared transform, foot-seat checks and empty/full/splash tests with physical water. Proposed numerical tolerances in its metadata are review proposals only. Do not activate until the local lane accepts them.
8. **Only then expand the pack.** Seasonal swaps need stable root pivot, trunk and major branches, scale, and occupied anchors; foliage silhouettes can naturally differ. Generate remaining seasons/states only after one source-to-runtime path has passed.

Stop condition for this handoff: six preserved sources and a clearly bounded next gate. Zero admitted sprites, no runtime activation, no further image generation in this batch.
