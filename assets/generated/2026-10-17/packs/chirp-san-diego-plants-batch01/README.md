# San Diego native plant production batch 01
Six actual generated originals across three explicit species, plus uniformly resized 512-square runtime candidates. This is the first local batch, not the whole requested collection.

- Coast live oak (Quercus agrifolia): independent woody structure and evergreen foliage overlay. Shared root is invariant by construction because the wood is reused. Bare structural art is NOT a biological winter state: coast live oak is evergreen. Shape and fine-leaf readability need botanical/art review.
- Toyon (Heteromeles arbutifolia): green evergreen complete base and independent red-fruit overlay. Composite preserves exact base/root. Fruit is seasonal, foliage does not turn all orange. 85.79% of solid fruit pixels overlap the base silhouette; this is not proof that all tiny pedicels attach to a twig. Composite visually coherent at review size, attachment rig remains unverified.
- California buckwheat (Eriogonum fasciculatum): whole-shrub pale flowering and rust-colored spent flower/seedhead states. Rust heads are normal seasonal succession, not a dead or drought-stressed whole plant. The generator changed some foliage and root pixels despite preservation instructions. Alpha128 IoU 0.86815; root bottom approximately (615,1183) versus (614,1186). Static candidates, not pixel-invariant transition.

All source canvases actually 1254 square; preserve full canvas and shared coordinate system. No auto cropping, stretching, cleanup, alpha thresholding or recoloring was applied to source. Build script creates QA composites and uniform nearest-neighbor derivatives only. Sources have fine partial-alpha texture, not strict palette-limited pixel art; judge at final scene scale before admission.

Source hashes, alpha bounds, exact prompts, proposed root/pivot coordinates, world-size assumptions and missing states are in manifest/provenance. Wind/deformation remains proposed engine work, not delivered animation. No snow/default orange autumn imposed on this coastal/inland southern California set. Rain, heat stress, recovery, flowers/fruit gaps, detached local leaves and branch masks remain explicit backlog.
