# San Diego plants batch 03: lemonadeberry and California fuchsia
Six real generated source PNGs create six static assembled states across two named species. Full-resolution originals are unchanged and hashed; 512-square runtime candidates use uniform nearest-neighbor whole-canvas resizing.

Lemonadeberry (Rhus integrifolia): clean standing evergreen base, independent pale-pink spring-flower overlay, independent pink/red fruit overlay. Broad leathery elliptic leaves distinguish the intended shrub from citrus and narrow-leaved toyon. The fruit is stylized and enlarged for game readability; final botanical/art approval remains open.

California fuchsia (Epilobium canum): clean standing narrow-leaf gray-green base, independent scarlet/red-orange flower overlay, independent mature seed-capsule overlay. Species-level wild-type impression, not a certified subspecies or named cultivar. Seed capsules and a few silky seeds are normal reproduction; the seed state is not a dead/drought-damaged plant. Flowers and developing/mature capsules can naturally overlap in time; the preview isolates states for review rather than enforcing a biological calendar.

Both base images end cleanly at ground contact without exposed roots. Full-frame overlay coordinates are shared with the corresponding base. No full-plant state rerolls were used. Base source bytes remain identical across assembly, avoiding the earlier shrub-regeneration drift. However, generator alpha-1 residue exists in the lower tenth of each overlay: rendered composites are 99.67–99.97% exactly unchanged there, not mathematically pixel-identical. This is measured and retained, not silently thresholded. Visually no root movement appeared. A future authorized alpha-cleanup/admission step should address residue.

Composite attachment was visually inspected. Overlay alpha128 overlap with the host base is 94.09%/97.08% for lemonade flowers/fruits and 26.72%/49.23% for fuchsia flowers/capsules. Outward-projecting flowers naturally extend outside the host silhouette; these figures are measurements, not attachment quality scores. Individual flower/pedicel anchors are not authored. Some fuchsia flowers read short/tightly flared at preview size; botanical proportion and final-size readability need review.
