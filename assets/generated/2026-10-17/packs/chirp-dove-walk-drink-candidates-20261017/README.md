# ChirpNeighbors private asset production

This directory is the production handoff, separate from both October 12 repository snapshots and the Mac implementation. Nothing here is published, pushed, selected in the app, or claimed integrated.

`queue.json` is the single queue. States: queued → generating → generated → reviewed → staged → integrated. Review records may reject a batch; state alone never means accepted. External parent-reported counts are distinct from locally verified files.

Original model outputs and exact prompts are retained for every successful call. Derivative frames, timing, anchors, hashes, reviews and playable previews are produced from actual output pixels. Registration is not new body animation. No frame is synthesized through runtime bobbing.
