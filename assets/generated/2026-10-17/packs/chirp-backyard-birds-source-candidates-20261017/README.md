# ChirpNeighbors: common backyard bird source candidates

Two unapproved source candidates: adult male Northern Cardinal and Mourning Dove. Both are static, right-facing, full-body, open-eye standing poses. No blink frames were made; no animation coherence is claimed. Generated with the built-in image tool using the existing blue-jay v2 as a style reference only. No runtime file writes or activation.

## Review result
Species identity is readable at enlarged and proposed game scales. Cardinal shows the red crest, heavy red-orange bill, black mask/throat, red body and long tail. Dove shows a small rounded head, slim dark bill, warm buff breast, black wing spots and long pointed tail. Dove is deliberately longer, lower and smaller-headed. Cardinal crest and both birds' layered feathers remain stylized; these are source art candidates, not scientific plates.

The preview composites genuine alpha over warm light and blue-black dark backgrounds. The apparent colored haze in some raw RGB viewers is not visible as a surrounding glow in these composites. Both sources have partial alpha up to 254 rather than fully opaque interiors; preserve originals and validate a production alpha/palette adapter separately. Feet are present, but at 1x the fine toes are delicate and the dove tail is thin. A production pixel-density pass should preserve those contacts. No pixel-grid cleanup or mask repair was applied.

Proposed silhouette widths: cardinal 62 world pixels; dove 78 world pixels, against the existing blue-jay candidate's 72-pixel proposal. These are visual art-direction estimates, not biological measurements. The preview shows 1x and nearest-neighbor 2x. These are NOT approved runtime sprite sizes. Manifest contact anchors are approximate manual source coordinates and require integration validation.
