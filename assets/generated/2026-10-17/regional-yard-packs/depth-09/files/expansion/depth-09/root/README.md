# One layered inland San Diego test yard

This is a source asset package for the existing `scene.san_diego_inland_canyon` identity. Four seasonal recipes share separately usable sky, distant mountains, fence and ground; independent feeder/bench instances, sycamore wood/canopy, localized litter and blowing-leaf review parts remain separate. Five complete static renders show four seasons plus a conditional winter summit-snow option. The default winter recipe has no snow. The snow alternate is a whole mountain layer, not an independent snow-only overlay.

The batch reuses depth06 sky and four actual seasonal grass rasters, the existing cedar row and props, and seven existing California sycamore parts. Only two mountain originals were generated. Native origins did not meet the requested height; declared translation `[0,-120]` gives summit headroom, with alpha<8 cleanup on derivatives only. Native origins and tighter `-150` studies are retained. The snow edit changes the skyline by -2 to +3 source pixels and resynthesizes fine texture; no pixel lock is claimed. Warm/granular mountain detail, repeated ground texture and a strict common logical pixel grid remain style limits.

The full visible floor is authored as `[0,494]..[1536,1024]`, across every horizontal row, rather than a central empty square. A separate example mask subtracts only the current optional instances' proposed footprint envelopes. Removing those instances restores the exact full ground mask. Source canvas is 1536x1024; viewport is crop `[0,160,1536,1024]` at 960x540 or 384x216. The shared 130 source pixels/metre and elevations are illustrative, not surveyed geometry or camera calibration.

Usable visual masks are real raster files: exact soft alpha and declared binary coverage for fence/props, sycamore wood/canopy coverage and root-band visual coverage, and separate mountain alpha. The full-ground raster exists and is reviewed, but its support meaning remains authored/proposed. These masks are not automatically inferred collision volumes, ground meshes, heightfields or physical perch authority.

Eight manually authored fence cap/post segments pass visible-material sampling. A bench armrest trial crosses a void and is held. Every bird foot/beak/body fit, perch capacity, ground support, instance collision and physical contact remains unvalidated. Geometry/material/weather proposals are outside application contracts. Cedar wet surfaces, hydrology, snow accumulation/melt and material solvers are not implemented.

The managed sycamore is conditional planted/riparian-context vegetation. Its source tree/leaves remain provisional for botany/style and outer-twig registration. The small left-edge scene crop is intentional; complete source masters remain unchanged. Summer grass is actually dry/golden; autumn foliage/litter is localized to this deciduous tree. Winter lowland ground stays snow-free; distant mountain snow is only an optional after-storm high-country appearance. Regional evergreen yards must not inherit this tree's deciduous behavior.

`tree_motion.py` is the sole tree/leaf motion implementation. The complete-yard renderer calls it for each phase, producing an actual offline sway/blowing-leaf loop with fixed root, wood and attachment cores. This is compound canopy deformation plus authored fading leaf paths, not runtime wind, anatomical rigging, leaf collisions or simulated settling.

The runtime integrator owns schemas and admission. The inspected current strict V1 has three inline-rectangle layers and does not admit these PNG/mask fields. A reviewable field proposal is included. Cross-thread messaging is unavailable here, so parent relay and integrator agreement remain pending; no live engine adoption, application edit, owner acceptance or immutable runtime selection is claimed.

All exact prompts, originals, owned references/rights lineage, failed studies, transforms, hashes, dimensions, anchors, footprints, review states and reusable source code are retained in the package/manifests. Source publication and Library receipts are appended externally after package freeze. No generation remains active after the two bounded calls.
