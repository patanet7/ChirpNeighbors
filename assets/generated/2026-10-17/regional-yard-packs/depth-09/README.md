# Depth09 source candidate

This source-only pack provides one inland canyon scene family with actual spring,
summer, autumn and winter layer recipes. See `depth09-catalog.json` and the published
Master under `files/expansion/depth-09/root/` for exact identities and source paths.
Two new image-generation calls completed; no generation is active or queued.

The raster masks contain actual visual coverage. Placement envelopes, fence/perch
segments, depth, elevation and physical scale are authored proposals. They are not
collision geometry, bird-anatomy validation, adopted runtime contracts or owner
acceptance. The full ground remains available except proposed instance footprints
while those instances are present. Tree outer-twig joins, perch anatomy and strict
shared pixel style remain under review.

Winter has no default yard snow. A separate distant summit whole-raster alternate
represents a conditional high-country storm; it is not a separable snow-only layer.

Original delivery archives were snapshot packages and private transport, not public
replay dependencies. Public source replay is provided by `verify_depth09.py`; consult
its command-line help for verification options. Canonical repository references
replace private transport locations. Published JSON hashes are reconciled separately
from preserved original-source digests. The Master's publication-preparation field
is historical snapshot metadata; this catalog marks the source candidate and makes
no Git-merge or runtime-adoption claim.

`manifest.json` and `coverage/depth-09.json` describe the source records. `SHA256SUMS`
covers every file currently inside this pack except itself, including replay tools
and these derived publication documents. References reused from earlier packs are
recorded by canonical repository path and digest in the manifest.
