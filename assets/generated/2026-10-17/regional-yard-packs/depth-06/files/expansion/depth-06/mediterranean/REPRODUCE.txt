Run python render.py from any directory to rebuild exact scene composites, viewport/contact previews and foreground source crops from relative original paths. Run python wind_proof.py to rebuild small source-only mild/heavy GIFs and six representative PNGs per clip. The scripts use generated art; they do not paint scenery. Originals are unchanged. Integer translations preserve source pixels but scene clipping is explicitly part of each draw contract. No app/runtime integration or physics is included.
