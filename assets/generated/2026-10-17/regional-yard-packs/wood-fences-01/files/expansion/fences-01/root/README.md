# ChirpNeighbors wooden fence source batch

Three styles: cedar privacy, weathered vertical boards and light aged picket. Each has a section, closed gate leaf, corner and flat-capped post. These are actual imagegen art with real alpha, exact source originals/prompts and measured extraction metadata.

Four clean coastal foundations provide spring, summer, autumn and winter. Twelve scene contracts combine each style with all four seasons. Sky/distance/ground remain flattened inside each foundation; fences are supplied as separate RGBA rows and independent component sprites. No movable plants or furniture are baked into the foreground.

The source camera is1536×1024. Review crop[0,160,1536,1024] exports960×540 and384×216 with nearest-neighbor sampling. Render item transforms reproduce the source-sized fence layer. Individual scale normalization is a review choice; generated proportions did not satisfy nominal2m/1m calibration. Corner projection and seamless snapping remain unverified.

Root reviewed actual normal/mobile views. Gate leaves are suspended rigid art with proposed hinges/latch/clearance, not ground-rooted panels. Metadata identifies potential flat-cap perches, foot contacts, endpoints and zero-weight wind attachments. Those fields do not implement interaction, animation or physics. Open/ajar gates, weathering/wet variants and actual Mac contacts need additional work.

All four seasons are present. Southern California winter is mild with cooler light/greener lawn; no default snow. Summer and autumn can both be dry. Fence material is static year-round. Seasonal plant state and irrigation belong to independent placeable entries; automatic seasonal selection is not implemented.

Generated and scoped-reviewed source candidates, staged for intake. Runtime integration and owner acceptance remain false. This source batch does not edit the Mac application or its active catalogs.
