# San Diego plant repairs and cedar utility objects

`repair-catalog.json` is the source intake: eight existing-schema asset/variant records, canonical sprite/module paths, registered assemblies, exact image hashes, source manifests and two actual gentle-wind proofs. Paths start at the repository root. `manifest.json` reconciles all source files and records private-to-public metadata transformations. Images and five non-sensitive exact prompts retain their original bytes; existing art is referenced by hash without copying it again.

This checkpoint adds a connected healthy oak canopy, a fibrous deergrass crown with unchanged existing fans, bladderpod, hollyleaf redberry, and four matching utility objects: wall tool rail, step stool, seed canister and watering can. It preserves the earlier held oak/deergrass attempts and first bladderpod leaf attempt. Proposed dimensions, contacts and interaction points are intake data. Shrub alpha maxima of 253/254 and the darker/glossier green metal are disclosed source limitations.

Generated, scoped-reviewed and staged are source production states. Final botanical/style review, owner acceptance and Mac camera/physical fit remain pending. Integrated and accepted remain false. Wind proofs are offline compound-part deformation/rotation with fixed attachment/root checks; they do not implement runtime wind or anatomy. Dry/seasonal shrub variants still need art.

Existing `seasons-01` and `depth-06` checkpoints preserve all four seasons for each of five yard options. Yard-scale composites here reuse those review plates and introduce zero new scenes. Flat shrub/prop sprites do not imply independent wood/leaf/hardware layers. Oak foliage and deergrass parts have actual separate RGBA files.

Run `python3 verify_repairs.py` from this directory for hashes/alpha/decoded registration checks. Run `python3 replay_repairs.py` for isolated replay of both GIFs and yard/assembly outputs (Pillow + NumPy). No app modules or network are required. The source application and paused runtime worker are unchanged. Generation is stopped after five completed calls.
