# Compact marine courtyard proof 01

One original static layered yard proof for `scene.san_diego_compact_marine_courtyard`, variant `analyst_reference_guided_proof01_v1`. Three real independent image-generation calls produced the opaque distance base and two alpha layers (ground/boundary/garden border/lawn; sparse foreground). All originals share 1536×1024 and remain unchanged. Their contents remain flattened within each layer.

Guidance was analyst text only. The Mac analyst inspected actual reference pixels, but this worker did not directly inspect those source pixels; no source screenshot was available or supplied to generation. Named attribution and source evidence stay private and are excluded from these packages. No third-party source image bytes are redistributed. Existing project yard art is included only through review derivatives for before/after comparison.

Composite order at origin [0,0]: distance.r1 at depth0; ground.r1 at10; canonical birds/placeables reserved at20; foreground.r1 at30. The layer registration was visually reviewed and remains provisional. No semantic decomposition, calibrated physical alignment, animation, weather/light overlay, physics, bird/contact coupling, app staging or integration is claimed.

The quiet lawn is a managed irrigated state, not a default unirrigated San Diego landscape. Dry/reduced-irrigation, clear afternoon, dawn/dusk and damp cool-season variants remain missing. Runtime weather/light overlays remain separate requirements.

Known defects: dense grass microtexture may compete with dark birds; base uses some smooth atmospheric transitions; foreground bounds exceed targets; faint stray alpha and near-opaque ground persist; compact enclosure and marine overcast identity are weak. This is a reviewed provisional proof, not accepted canon.

Review previews include light/dark actual-layer contact sheets, a full composite, and normal/mobile color/greyscale before/after comparisons. The baseline is the prior project managed patio, a different composition: comparisons do not establish physical pixel alignment or controlled A/B improvement. Luminance/texture proxies are labeled with caveats and do not measure real bird recognition. No artificial bird markers were used.

Canonical intake, commit, remote SHA and PR verification remain pending Mac ownership. No application or Git changes were made.
