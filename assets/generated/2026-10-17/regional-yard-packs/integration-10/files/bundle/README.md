# Selected San Diego inland yard source bundle

One editable assembly of the existing `scene.san_diego_inland_canyon` family, with four existing seasonal recipe IDs. This is an intake projection of the established inventory, not another catalog or an admitted application package. No new image generation was used.

Run `python3 verify_bundle.py --bundle .` and `python3 render_bundle.py --bundle . --output previews` with Pillow installed. `yard-source.json` is the assembly entry point. Edit `root_source_px` or hide any of the four instances using the renderer API. Tree wood and canopy retain full native sources, including pixels outside the original left scene crop. Feeder, bench and bladderpod are independent sprites. Four yard seasons are actual ground/tree selections; bladderpod is the same conditional healthy flowering/pod artwork, not four shrub states.

`source-image-index.json` freezes 107 logical image references into 69 unique image files. Its exact file SHA256 is the registered-ground `sourceReleaseDigest`. `registered-ground-candidate.json` and `expected-ground-release.json` use the existing runtime's unadmitted candidate contract. Ground coordinates are authored units, with source pixel origin [0,494]. The matrix maps that full-width rectangle to world [0,208.75]..[960,540]. This is a mathematical image registration, not physical calibration, metres, elevation or support approval.

Sky is a real RGBA derivative of the delivered RGB sky: RGB unchanged, alpha255 above source row494 and0 below. Clouds remain flattened with the blue sky. Four ground derivatives preserve RGB and normalize alpha255 over the explicitly filled floor. Mountains and fence retain existing transparent source bytes. The optional distant summit-snow layer is a whole mountain alternate, off by default; there is no snow-only overlay or default lowland snow.

`texture-review/` contains 33 strict review-only manifests for actual 480x270 RGBA exports, at world960x540 and density0.5. One empty winter canopy is recorded but has no manifest. These are registered compositor panels. Their pivot[0,0] and alpha-sample contacts are bookkeeping, not native actor roots or functional bird contacts. Native actors have separate pivots/scales and proposed placement in the assembly. The pinned runtime's strict manifest parser accepted the33 inputs; its official server PNG sanitization/review-export receipt and route adapter remain pending. No validation receipt was invented.

Masks describe exact soft alpha or explicit threshold coverage. The full814080-pixel floor and current-instance envelope subtraction are authored raster diagnostics. `proposed-support-and-instance-geometry.json` is separate from visual occlusion. Eight fence-cap/post segments passed visible-material sampling; the bench armrest trial remains held. Physical collision, support, height, bird body/foot/beak fits and perch capacity have no approval.

Current feeder and bench source identities match existing runtime entries, but this assembly's proposed paint scales differ from their catalog geometry. The integrator must preserve current geometry or review a version with pivots, footprints and all functional slots reconciled. The shrub/tree need explicit scene/object ownership. `field-requirements.json`, `runtime-intake-checklist.md` and `integration-binding.json` record the exact existing contracts, completed source checks and remaining runtime work. No engine files, routes, allowlists or schemas were changed.

Selected sprite/layer bytes are self-contained here. `provenance-index.json`, `upstream-source-history.json`, `plant-selection.json` and `source-contact-checklist.json` preserve canonical source hashes and history pointers. Exact earlier prompts, originals, references and held studies remain in the immutable upstream publications and earlier Library source archives. Project/service rights lineage is recorded without claiming an independent rights, botanical or owner approval.
